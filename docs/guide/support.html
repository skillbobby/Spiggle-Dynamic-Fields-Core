Troubleshooting, FAQ, and support

Package spiggle/dynamic-fields-core version 1.2.0. Namespace Spiggle\DynamicFields.

Where to get help

  • GitHub issues (Core): github.com/skillbobby/Spiggle-Dynamic-Fields-Core/issues
  • Download Core: github.com/skillbobby/Spiggle-Dynamic-Fields-Core
  • Buy Pro: open a purchase issue on the public Core repo ($29.99 limited-time deal, normally $49.99).
  • Include package version, Filament version, PHP version, whether Shield is installed, and the output of php artisan dynamic-fields:verify when reporting mapper or persistence bugs.

Troubleshooting

Custom Fields menu is missing

  • Confirm DynamicFieldsPlugin::make() is on the panel.
  • If Shield already created manage_custom_fields, your role needs that permission or super_admin.
  • If licensing is enabled on a Pro install, activate a key under Fields License first. Unlicensed Pro servers hide Custom Fields when enforcement is on. Core-only installs do not require a license key.
  • If the permission does not exist yet, any authenticated panel user should still see the resource.

Fields exist but do not show on User edit

  • Target model must be the exact FQCN used by the mapper (App\Models\User).
  • The resource schema must call CustomFieldMapper::makeFormFields(User::class).
  • Clear definition cache (save the field again, or php artisan cache:clear).
  • Run migrate so tables exist.

Values do not persist

  • Add custom_fields to the model’s fillable list, or call syncCustomFields in a page hook.
  • Do not put a JSON custom_fields column on the host table; the mutator is an accessor, not a column.
  • File fields persist via Spatie, not the EAV mutator loop — the model must implement HasMedia.

File upload fails or is disabled

  • File fields are Pro. Install spiggle/dynamic-fields-pro and activate a license.
  • Install/publish Spatie Media Library migrations and storage:link.
  • Use HasCustomFieldMedia from Pro (or register collections yourself).
  • If you override registerMediaCollections(), you must call registerCustomFieldMediaCollections().
  • Check disk credentials for S3; local tests can stay on public.
  • GD or Imagick is required for image conversions.
  • MIME / size / dimension rules reject files before they attach.

N+1 queries on the Users table

Use ->withCustomFields() on the table query (starter Users table already does).

Target model dropdown is empty

Models must live under configured model_discovery.paths, extend Eloquent Model, and not be in exclude. Namespace is inferred from the path (app/Models → App\Models).

Duplicate internal name

Database unique index on (target_model, name). Clone appends _copy; rename before saving a second original.

Stale field definitions after import

Import already forgets cache per model. If you edited the database by hand, call FieldDefinitionCache::flush() or cache:clear.

FAQ

Is this a public form builder?

No. It attaches fields to existing admin resources. For public URLs like /forms/contact-us, use Spiggle Form Builder.

Why both boolean and toggle?

They store the same way and both render as Toggle. Use the type name that matches how you talk about the control.

Can users invent tags that are not in Options?

TagsInput allows typed tags; options feed suggestions and badge colors. Values that are not in the map still display (label = raw value) with a fallback color.

Does rich textarea sanitize HTML?

Not in this package. Values are stored as submitted from the Filament panel. Public Form Builder sanitizes guest input separately.

Can I attach fields to models other than User?

Yes. Discover or type the FQCN as target, add the traits, and map in that model’s Filament resource.

Will deleting a field delete values?

Value rows foreign-key to the definition with cascade on delete. Media on the host model is not automatically deleted when you delete the field definition — clean collections in the host if needed.

What did Core v1.2.0 change?

Core is a public MIT package: 12 free field types, Field Manager, mapper, export/import. Premium types (file, tags, multi-select, RichEditor, visibility, clone) require Pro. v1.1.0 originally bundled those extras in a single private package.
