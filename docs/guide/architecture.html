Architecture

How Dynamic Fields is put together

The plugin is an EAV layer plus a Filament mapper. Definitions are data. Rendering is generated at runtime from those definitions.

Core concepts

Definition

A CustomField row: target model FQCN, internal name, human label, type, required flag, validation rule strings, meta JSON, sort_order.

Options

Rows on custom_field_options for select, radio, multi-select, and tags: label, value, optional badge color, sort order.

Value

One row per field per entity. Unique on (custom_field_id, model_type, model_id). Stored as LONGTEXT plus a value_type used by ValueCaster.

Mapper

CustomFieldMapper turns definitions into Filament form components, table columns, and infolist entries using the nested state key custom_fields.{name}.

Schema extras

  • custom_fields.sort_order — deterministic display order.
  • Unique (target_model, name) on definitions.
  • Unique value row per field per entity (see above).
  • MySQL/MariaDB uses a 191-character prefix index on (custom_field_id, value) because MySQL cannot index full LONGTEXT. Other drivers get a full composite index.
  • Options gained a color column in a later migration (used by tags badges).

How form values persist

  1. Filament fills nested state custom_fields = ['first_name' => 'Ada', …] onto the model.
  2. setCustomFieldsAttribute queues that array on the model.
  3. On the Eloquent saved event, the trait writes each pending value via setCustomFieldValue.
  4. File fields are skipped in that loop. Spatie Media Library attaches the upload; listeners then sync metadata into the EAV row.

That is why host Create/Edit pages usually need no extra hooks, provided custom_fields is fillable (or you call syncCustomFields yourself).

Mapper behavior

  • Loads definitions through FieldDefinitionCache::forModel().
  • Applies label, required, extra Laravel rules, hint, placeholder.
  • Conditional visibility: Pro. meta.visible_when.field + value, or flat meta.visible_when_field / visible_when_value.
  • Non-file components hydrate from $record->getCustomFieldValue().
  • Table search uses whereHas('customFieldValues') with a LIKE on the stored value.
  • Boolean/toggle columns are Filament icon boolean columns.
  • Tags and multi-select colored badges are Pro.
  • Image file fields (Pro) can use Spatie image columns/entries when image_only or image_editor is set.

FieldTypes helpers: requiresOptions, storesArray, isBoolean, isFile, hasColoredOptions (tags only).

File fields (Pro)

File uploads are not part of Core. With Pro:

  1. Host implements HasMedia and uses HasCustomFieldMedia.
  2. Filament component is SpatieMediaLibraryFileUpload on collection custom_field_{name} (or meta.collection).
  3. Disk: meta.disk (unless default) or dynamic-fields.files.default_disk.
  4. On media added/deleted/collection cleared, FileFieldSynchronizer writes JSON metadata into EAV: collection, disk, media ids, uuids, file list (name, mime, size, url, custom properties).
  5. getCustomFieldValue() for file types reads live media, not a stale blob.

Custom properties on each media item: original name, mime, size, field name, optional directory hint. Filenames can be slug-optimized.

If the host does not implement HasMedia, the File component still renders but uploads cannot attach. If the Spatie Filament plugin class is missing, the mapper shows a disabled text input with a helper message.

Definition cache

FieldDefinitionCache stores serialized definitions + options in Laravel Cache for ttl seconds (default 1 hour), keyed by {prefix}:definitions:{md5(model)}. Saving or deleting a field calls forget() for that target model. Disable with cache.enabled = false while iterating on definitions if needed.

Events

  • CustomFieldCreated, CustomFieldUpdated, CustomFieldDeleted — dispatched from the model.
  • CustomFieldValueSaved — after each value upsert, with the value record and host model.

Listen in the host app for webhooks, search indexing, or audit.

How this differs from Form Builder

PurposeExtra attributes on an Eloquent recordStandalone public/admin forms
StorageEAV on the host (files via Spatie in Pro)form_builder_submissions.data JSON
UIInjected into host Filament resourcesOwn Forms + Submissions resources + public Livewire page

Form Builder’s Form::importCustomFields($ids) copies definition snapshots into a form schema. After import, the two copies are independent.
