Free in Core

Everything below ships in spiggle/dynamic-fields-core. Clone the public repo, require it with Composer, and start defining fields.

01

Core field catalog

Text, email, phone, URL, number, plain textarea, select, radio, date, datetime, boolean, and toggle — mapped to native Filament inputs.

02

Filament Field Manager

Create and manage definitions in the panel. Options, validation rules, hints, and sort order appear where operators expect them. Pro types show a PRO badge until you license Pro.

03

Drop-in model trait

HasCustomFields wires any Eloquent model. CustomFieldMapper builds form, table, and infolist components from your definitions.

04

EAV done carefully

Definitions, options, and values are normalized tables — not a dumping-ground JSON column. Events and caching keep reads snappy.

05

Ops tooling

Seed standard user fields, export/import definitions, and verify setup. Shield-compatible permission names are ready when you use Spatie Permission.

06

Open source

MIT licensed. Download from GitHub. Pro is a separate paid add-on — Core source does not include Pro drivers or license code.

From zero to custom attributes

Three steps between a Core install and fields live on your resources.

1

Install Core

Download from GitHub or require spiggle/dynamic-fields-core, publish config, migrate, and register DynamicFieldsPlugin on your Filament panel.

2

Trait your model

Add HasCustomFields. Map components with CustomFieldMapper in your resource schema. File fields need Pro plus the media trait.

3

Define in the panel

Operators create Core fields under System → Custom Fields. No migration. No redeploy. Values save with the host record.
