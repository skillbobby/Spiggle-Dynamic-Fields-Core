FAQ

Quick answers

Do I need to write code for every new field?

No. Your team defines fields in the Filament panel — pick a model, set the label, choose a type, save. The form, table column, and storage are handled for you. No PHP edits, no migration per field, no redeploy.

Does marketing need a developer when they want a new field?

Not for Core field types. An admin can add a Department dropdown or Phone field in minutes under System → Custom Fields. It shows up on create and edit forms right away.

How fast can I ship a new profile field?

Usually minutes: create the field, assign options if needed, refresh the user form. Values save with the record automatically. Watch the demo — we add a Department select live in the panel.

Can I attach fields to Users, Products, or other models?

Yes — any Eloquent model. Add the HasCustomFields trait once, wire the mapper in your Filament resource, then create as many fields as you need from the UI.

What's the difference between Core and Pro?

Core is free and covers everyday fields: text, select, dates, toggles, and more. Pro unlocks file uploads, tags, multi-select, rich text, conditional visibility, and clone — ideal when you need more than standard attributes. Same no-code workflow; Pro just opens more types.

Will custom fields slow down my app?

Definitions are cached and values live in normalized EAV tables — not a bloated JSON column on every row. Built for admin panels and typical CRUD workloads, not millions of writes per second.

How does licensing work?

Core is MIT and free forever on GitHub. Paid tiers (Solo, Pro, Business) include a license key you activate in Filament. Solo = 1 site, Pro = up to 5, Business = unlimited with priority support.
