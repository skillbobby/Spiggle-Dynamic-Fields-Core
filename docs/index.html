FAQ

Quick answers

What's in Core vs Pro?

Core is free and MIT-licensed: standard field types, Field Manager, and the mapper. Pro adds file uploads, tags, multi-select, rich text, visibility rules, and clone — delivered as a private licensed package.

Do I need migrations for each field?

No. Field definitions and values use the package EAV tables. Create a field in the panel and it appears on your resource.

How does licensing work?

After purchase you receive a license key. Activate it in Filament under Fields License. Solo allows 1 production site, Pro up to 5, Business is unlimited with priority support.

Which Filament versions are supported?

Filament 3, 4, and 5. The demo and docs target Filament 5 Schema API.

Where do I report bugs?

Open a GitHub Issue on the public Core repository.
